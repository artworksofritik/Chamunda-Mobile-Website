# 📱 Chamunda Mobile — Mobiles & Accessories Showroom Website

Official interactive web showcase for **Chamunda Mobile**, premier smartphone and genuine mobile accessories showroom located in Sector-8, Airoli, Navi Mumbai.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fartworksofritik%2FChamunda-Mobile-Website)

---

## 🌟 Key Features

- **🕒 Dynamic Live Store Status:** Real-time Indian Standard Time (IST) detection showing whether the showroom is currently Open or Closed (10:00 AM – 9:30 PM).
- **📱 Interactive Smartphone Catalog:** Instant search and category filtering across Apple iPhone, Samsung Galaxy, OnePlus, vivo, and Realme with live demo badges.
- **🔍 Quick Specs & Customization Modal:** Interactive storage selection (128GB to 1TB) and 1-click WhatsApp enquiry pre-filled with the exact model selected.
- **⚡ Original Accessories Showcase:** Studio photography and specs for genuine chargers, MagSafe packs, and drop-tested cases.
- **🧮 Smart In-Store Tools:**
  - **Smartphone EMI Calculator:** Interactive price and down-payment sliders with dynamic monthly installment breakdown.
  - **Old Phone Trade-In Estimator:** Instant device evaluation with ₹2,000 showroom exchange bonus.
- **📸 In-Store Photo Gallery:** High-resolution photography of the physical Airoli showroom with interactive lightbox preview.
- **⭐ Verified Customer Reviews:** Google 4.9-star review summary with an interactive "Write a Review" feature that stores submissions in `localStorage`.
- **📍 Location & Directions:** Showroom address (Opp. Apple Hospital, Sector-8, Airoli), direct calling links, and toggleable Google Maps embed.

## 🚀 Local Development

To run this website locally on your machine:

```bash
# Clone the repository
git clone https://github.com/artworksofritik/Chamunda-Mobile-Website.git

# Enter the directory
cd Chamunda-Mobile-Website

# Start the local server
node server.js
# Or on Windows, double-click start-localhost.bat
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.

---

## ☁️ Deploying on Vercel

This repository is pre-configured with `vercel.json` for 1-click zero-config deployment:

1. Go to [Vercel](https://vercel.com) and log in.
2. Click **"Add New"** > **"Project"**.
3. Import `artworksofritik/Chamunda-Mobile-Website`.
4. Leave all build settings as default (Framework Preset: **Other** / Root Directory: `./`).
5. Click **"Deploy"**!
